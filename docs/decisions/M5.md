# Décisions d'exécution du jalon M5

Ces décisions précisent ou amendent les ADR pour l'exécution de M5. Une section par lot.

## L20b — cœur KEPUB

Date : 2026-11-18. Exigence EF-BIB-015, volet KEPUB.

`library.application.kepub.kepubify` est le cœur pur, livré seul : une fonction, d'octets d'EPUB (déjà neutralisé, traité comme non fiable) vers octets de KEPUB, en Python seul, sans binaire externe. Les bornes ne sont pas réinventées : la lecture passe par `safe_open_archive` (comptage, tailles, ratio, chevauchement — ENF-SEC-002), l'écriture par `ArchiveWriter` (horodatages fixes : mêmes octets entrants, mêmes octets sortants) et l'analyse XML par `safe_parse_xml` seule (ENF-SEC-014 : aucune DTD, donc aucune entité n'est jamais résolue). Tout refus est `KepubError`, une `ValueError` typée à mot `reason` stable, jamais une erreur 500.

**Ce lot ne livre aucun câblage** : pas de flux OPDS, pas de route `/lite`, pas de cache, aucun appel à `kepubify` hors de ses tests. Ces branchements dépendent des lots L20a (renditions) et L17a (serveur léger), non livrés ici ; ils s'écriront dans leurs lots, sur cette fonction inchangée.
